家庭菜单 · UI 美化方案 ② 空态

体检清单的 P1。现在 app 里其实有 三套空态：
① app.wxss 的 .ep-img —— 一个 128rpx 纯色圆圈，里面什么都没有（菜库 / 采购清单 / 日历 共用）； ② components/empty —— 灰色圆 + 一条灰横杠（菜品管理用，颜色还全是写死的）； ③ 今晚页 —— 用真插画 /assets/hero/couple.jpg。
一个精致、两个像占位符。下面先把两种凑合的做法摆出来，再给三个方案。

空态是「用户会反复看到」的界面 —— 菜库刚建、新的一月、采购清单清空之后，第一眼都是它。 现在它长得像「这里坏了」，而今晚页那张插画证明我们是有能力做好的。

1三个方案都以「菜库还是空的」为例

A 圆底 + 线性图标 · 最稳

菜库
菜库还是空的
点右下角添加，或去「今晚」一键填入示例菜库

沿用现有的线性图标（就是底部 tabBar / 编辑页色块里那一套），只把「空圆圈」换成「圆底 + 图标」。 一行 CSS + 一个图标文件，风格天然一致。

B 暖色渐变圆 + 白图标 · 最有存在感

菜库
菜库还是空的
点右下角添加，或去「今晚」一键填入示例菜库

圆底用和「无图占位块」同一套暖色渐变（#E7A176 → #C0613F），白色图标 + 一圈投影。 和菜品卡片的占位块是同一个视觉家族，比 A 更「亮」，也更像 app 自己的样子。

C 小插画 · 最有画面感

菜库
菜库还是空的
点右下角添加，或去「今晚」一键填入示例菜库

不再是一个圆，而是一组元素：冒热气的碗 + 一片菜叶。画面感最强，也和今晚页那张插画接得上。 代价是要多画几张（菜库 / 采购 / 日历 各一张），而 A、B 只要换图标。
