编辑菜品页 · 4 张并排对比

左起：现状 → 方案 A 卡片分区 → 方案 B 大图头 → 方案 C 极简清单。同一份内容（蛋炒饭），按真机 1:1 渲染，你直接看哪个顺眼。

现状的问题（不是「感觉丑」，是有具体几条）

  1. 卡片通栏：页面左右没有内边距，白卡顶到屏幕两条边，圆角被切掉 —— 看着像没做完的列表，不像卡片。
  2. 一批写死的灰色：分隔线 #F5F6F7、虚线框 #DCDFE5、箭头 #C9CDD4、开关 #FF7A45。全站只剩这一页没换成主题变量，深色模式下会露出浅灰，而且和全局的暖色调不是一个体系。
  3. 文本类字段右对齐：菜名、分类都往右靠，中文长句右对齐很难读；标签固定 100px，「食材清单 + 那句说明」挤在一起。
  4. 食材 / 做法输入框通栏：字直接顶到屏幕边（截图里「隔夜饭,鸡蛋,葱,火腿」就是），标签和输入不在同一个视觉块里。
  5. 保存要滚到底：表单很长（下面还有标签、上架状态），保存按钮在页面最末尾，容易漏。

思路：不要卡片，用小灰标题分组 + 通栏分隔行（iOS 设置那种）。 长文本字段单独占一行、左侧一条橙色竖线标出来。 一屏能看到更多字段，改起来最快；代价是不如 A/B 有温度，偏「工具」。

三个方案的共同点（不管选哪个都会改）

  • 页面上写死的灰（#F5F6F7 / #DCDFE5 / #C9CDD4 / #FF7A45）全部换成主题变量 —— 这是全站唯一没换的一页，深色模式下现在是错的。
  • 食材清单 / 做法步骤的输入框不再通栏，字不会顶到屏幕边。
  • 底部固定「取消 / 保存」，不用滚到底。
  • 长文本字段（描述 / 食材 / 做法）不再和标签挤在一行里。

我推荐 A

  • 改动最小、最不容易出意外；视觉上和「今晚 / 菜库 / 家庭」那几页的卡片语言完全一致。
  • B 更适合「菜品详情」那种以图为主的页面；用在编辑页，没配图时会显得空。
  • C 最干净，但和 App 其它页面的调性差得比较远，会显得像两个产品。
