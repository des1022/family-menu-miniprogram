方案四 · 让彩色只出现在「真的有含义」的地方

现在一屏里会同时出现好几种彩色的浅底方块，大半是纯装饰（区块图标、食材签）—— 每个单看都不难看，但叠在一起就分不清哪个是重点。下面把同一块界面「现状 / 改后」并排放。

① 菜品编辑页的区块头

现状 · 四个区块，三种颜色轮着用

菜品图片
基本信息
食材清单
做法步骤

红 / 琥珀 / 绿 / 红 —— 这四种配色不表示任何含义，纯粹是为了"不单调"。 结果是这四个区块看起来互不相干，而且和下面真正的状态色（绿色的"已上架"）混在一起。

改后 · 全部中性，靠图标区分推荐

菜品图片
基本信息
食材清单
做法步骤

图标本身就不一样（相机 / 文档 / 篮子 / 列表），不需要靠底色再强调一遍。 底改成浅灰后，四个区块从"四个频道"变成"一页里的四段"，页面安静下来。

③ 菜品详情里的食材签

现状 · 绿色底 + 绿字

食材
牛肉小米辣 生抽香醋

食材是"内容"，不是"状态"，用绿色会让它和真正的成功状态（已买 / 已上架）撞色。

改后 · 中性底；只有「命中忌口」才上色推荐

食材
牛肉 香菜 小米辣 生抽

平时是安静的灰签；一旦命中家人忌口才变红 —— 这样一个颜色出现就一定有含义， 和方案一（忌口）是同一件事的两面。

④ 规则表（定了这个，颜色一个都不用改）

颜色只允许用于明确不要用于
主色（陶土橙） 主操作按钮、当前选中、今天 区块图标等装饰
强调（琥珀） 只给「时间与记录 / 提示」：有记录的日子、日期胶囊、小建议、名次 纯装饰图标
成功（绿） 只给「已完成 / 状态」：已上架、已买、已确认、自检通过 食材签、区块图标、决策器图标
危险（砖红） 只给破坏性动作与警告（删除 / 忌口命中），且只用文字色、不填大色块 任何填充色块
中性浅灰 一切容器、分区、图标底、内容标签（食材 / 标签 / 提示条） —

合计改动：菜品编辑页 4 处 + 决策器 3 处 + 食材签 3 处（详情 / 安排弹层 / 今晚详情）， 每处只是把背景从某个彩色变量换成 --surf2。色值一个都不用动。
