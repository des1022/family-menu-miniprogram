## 建议的动手顺序

1. **先做 #1**（管理菜品页）：它是三页里唯一的「错」——自造配色 + 不跟主题。改完深色模式就齐了。
2. **再做 #4**（空态插图）：一次覆盖三个页面，是当前「最像没做完」的地方，性价比最高。
3. 之后按兴趣挑 #6 / #7（这两个是「加分项」，不改也不影响用）。

---

## 已经整齐了的部分（不用动）

- **今晚页**：卡片 + 插画空态 + 决策器，语言统一。
- **菜库页**：分类列（图标 + 名称 + 数量）、网格卡、悬浮 ＋ 收起、图片状态角标。
- **日历页**：刚改成格子块月历（`.cal-card` + `.tile`）。
- **菜品编辑页**：章节色块图标、图片位主视觉、底部固定保存条。
- **全局**：色板 / 圆角 / 阴影 / 四个主题块都在 `app.wxss`，换主题只改变量。
