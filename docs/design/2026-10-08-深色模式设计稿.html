04小程序侧的实现要点

① 跟随系统 + 手动三档

app.json 开启 "darkmode": true 并配主题变量文件；运行时用 wx.onThemeChange 监听系统切换；「家庭 → 设置」保留 跟随系统 / 浅色 / 深色 三档。

② 颜色全部走 CSS 变量

把 app.wxss 里写死的色值全提成变量（--pri / --bg / --ink …），深浅两套只换变量定义。这是批一的第一件事。

③ 底栏要与页面底分开

这个主题里页面底和底栏都是绿，必须用深一档的 #2F6A5C 做 tabBar 与操作栏，否则底部区域会糊成一片。

④ 照片上的标签用白色

「谁点的」这类压在照片上的胶囊用纯白底 + 深字，跟主按钮同一套语言，在绿底和照片上都清楚。

底色 #37776A、强调 #D2703F、按钮文字 #2A5F54 均为方案 B 原值，未做任何提亮或替换。照片为暖色渐变占位（已叠遮罩）。文件尚未提交 git。
