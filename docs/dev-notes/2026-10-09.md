## 「菜库左侧分类没有变化」的真正原因 = 用户看的是**旧构建**，不是代码问题

用户反馈分类列没变。核对链路：

1. 本地 `dishes.wxml` / `dishes.wxss` / `dishes.js` 都已是新版（图标在上、名称+数量在下）。
2. 远端 `main` 的 `6ec2143`（= 本地 `9fd9ad7` 的同内容提交）里 `grep cat-i-ic` 有命中，树内容一致
   （`git diff --ignore-cr-at-eol` 为空，差异只是 CRLF/LF）。
3. Actions 运行 `08:55:32Z`（16:55）`deploy-miniprogram` `mode=preview` on `6ec21437` → **success**。

所以代码与部署都没问题，是**用户手机上跑的还是老包**。

### 教训 / 规矩

- **本地与远端曾经分叉**：远端分支是早前用 GitHub REST API 造的提交（`api_push.py`，
  `<SHA>` 与本地不同、blob 里是 CRLF），本地又是另一条 `git commit` 出来的链。
  两边**内容一样、SHA 不同**。处理办法：`git branch -f backup-local <本地HEAD>` 后
  `git reset --hard origin/main` 对齐，之后 `git push` 直连（现在通了）恢复正常。
  **以后每次改动前先 `git fetch` 看有没有分叉。**
- `core.autocrlf=true`：本地 commit 里存 LF、工作区/API 推上去的是 CRLF，
  对比两个提交要加 `--ignore-cr-at-eol`，否则会看到「6451 增 6451 删」的假差异。
- **交付二维码必须登记来源**：下载产物时记下 `run_id → artifact_id`，
  命名带上时间（`2026-10-09-1711-preview二维码.png`），避免答应用户「这是最新的」结果给错。
- 另外补跑了 `mode=upload` 传一个新版本，让长期入口（体验版）也跟上新 UI
  —— 预览二维码短效，家人平时是从「最近使用」进体验版的。

### 1. 自绘确认弹窗 `components/ui-dialog`

- 方案 D 暖橙卡：圆形**白底**图标 + 居中标题/正文 + 取消在左、确定在右。
- **图标圆底恒为白色**（两种主题下都是），所以 PNG 里的描边色（陶土橙 / 砖红）可以直接写死，
  不用为深色模式再出一套图 —— 这是个能省事的取巧点，但要记住前提：底色不能变。
- 图标同上一轮的做法：内联 SVG 排成一行 → 无头 Chrome `--default-background-color=00000000`
  截**透明底** PNG → Pillow 切开。`assets/icons/dlg-warm.png`（面包碗）、`dlg-danger.png`（垃圾桶）。
- **新增 5 个变量到 app.wxss 的四个主题块**：`--dlg-bg` / `--dlg-tx` / `--dlg-bg-d` / `--dlg-tx-d` / `--dlg-btn2`。
  深色下不能复用 `--pri-l`，因为深色的 `--pri-l` 是 `rgba(255,255,255,.16)`（白色半透明），
  拿它当卡片底会变成一张白卡，不是暖橙卡。
- 组件的 `open()` 返回 Promise，`_finish()` 里先清 `_resolve` 再 `setData`，避免重复 resolve；
  上一个还没关就被顶掉时按「取消」结掉，否则调用方会永远 await 不到。
- 点遮罩 = 取消；**只有一个按钮时遮罩不响应**（那是提示，不是选择）。

### 2. 怎么让 15 处老调用点一行都不用改

`utils/util.js` 的 `confirm()` 通过 `getCurrentPages()` 拿当前页，再
`page.selectComponent('#uiDialog')` 找组件，找到就用自绘的，找不到退回 `wx.showModal`。
所以每个页面只要 wxml 里挂一个 `<ui-dialog id="uiDialog"/>` + json 里注册组件即可。

**破坏性配色用文案自动判断**（`/删|撤|移除|清空|清掉|丢掉|去掉|下架|重置/`），
这样 8 处会丢东西的操作不用逐个加参数；判不准时可以显式传 `opts.danger`。
另外新增 `alert()`，把 9 处 `wx.showModal({showCancel:false})` 也换掉 ——
不然自绘弹窗和原生提示框同时存在，反而更乱。

**踩坑**：`wx.showModal` 的错误提示里有 `\n`，自绘弹窗的正文要加 `white-space: pre-line`，否则换行丢失。
