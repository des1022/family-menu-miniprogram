## 修复 · 示例菜库填入失败（真机反馈）

**现象**：真机上点「填入示例菜库」→ 提示「填入失败，请重试」，一道菜都没进去。

**定位**：原实现有三个叠加的脆弱点，任何一个都能让整批无声失败：

1. `db.addDishes` 用 `Promise.all` 并发打 12 条 add。小程序端对云数据库的并发写有限制，
   且 `Promise.all` 只要一条 reject 就整批 reject —— 表现就是「一道都没进去」。
2. `db.addCategory(...)` 没有 catch。若 `categories` 集合缺失或权限不对，这一步直接抛错，
   **后面的菜品写入完全不会执行**。
3. catch 里只 `toast('填入失败，请重试')`，把真实的 `errCode / errMsg` 吞掉了。
   手机上没有控制台，等于完全没法定位。

**修复**：

- `utils/db.js`：`addDishes` 改为**顺序写入**，每 4 条 `sleep(200ms)` 避开频率限制；
  单条失败只记录不中断，返回 `{ ok, failed:[{name, err}] }`。`addDish` 补默认 `image:''` / `price:0`。
- `pages/tonight/tonight.js` `onSeed` 重写：
  - 分类逐个 `catch`，失败只 warn，**不再阻断菜品写入**
  - 先读已有菜名，**跳过同名菜**（重复点「填入」不会变成两份）
  - 带进度提示「正在填入 n/12」
  - 失败时 `wx.showModal` **把真实错误码显示出来**（部分失败显示前 3 条原因）
- `utils/util.js`：新增 `sleep(ms)` 与 `errText(e)`（把云开发错误翻译成人话 +
  给出「集合没建 / 权限不对 / 网络超时」的方向提示）。
- 新增 `db.pingAllCollections()` + 家庭页「**数据连接自检**」入口：
  逐个集合试读，直接在手机上列出哪个集合缺、什么错误码。以后这类问题不必再猜。
- 顺手：`onExport` 的四个读取加 `.catch(() => [])`（一个集合有问题不再让整份备份失败），
  并把 `shopping` 也纳入备份。

**教训**：批量写一律顺序化 + 单条容错；catch 里**不要吞掉 errCode/errMsg**；
本机没有微信开发者工具时，要在 App 内留一个能自己报错的诊断入口。

## 修复 · 云环境是空的（真机反馈，全部 5 个集合都不存在）

**现象**：上一条修复后弹窗给出了真实错误码 —— 12 道菜全部 `[-502005] Db or Table not exist: dishes`；
「数据连接自检」显示 **5 个集合全部不存在**（dishes / categories / records / members / shopping）。
所以不是代码问题：环境存在、可访问，但里面一张表都没有。

**已核对**：`utils/config.js` 的 `ENV_ID` 从未被改过（批一未触碰该文件，`git log -p -S"cloudbase-"` 全history只有一个环境 ID）。
说明是环境侧的问题（环境被重建 / 集合被删 / 指向了一个空环境）。

**关键知识（写下来免得再查）**：
- `Database.createCollection()` **仅支持云函数端**，小程序端不能建集合（官方文档明确标注「支持端：云函数」）。
  所以 App 内**无法自动建表** —— 只能控制台建，或走服务端通道。
- 服务端通道有两条：
  1. `POST https://api.weixin.qq.com/tcb/databasecollectionadd?access_token=...`（微信云开发 HTTP API，
     需要 AppSecret 换 access_token，可在 CI 里跑）；
  2. 云函数里 `db.createCollection(name)`（需要部署云函数）。
- 因此「集合不存在」的正确做法是**自愈 + 引导**：客户端检测到就明确告诉用户建哪几个。

**修复**：
- `utils/util.js` `errText` 重写：错误码 → 一句人话（`-502005` → 「集合还没建 —— 去云开发控制台新建，
  权限设『所有用户可读写』」）。原来把一整段英文文档链接糊在弹窗里，手机上根本没法读。
- `utils/db.js` 新增 `checkEnv()`（基于 `pingAllCollections`，返回 `{ready, missing, items}`），
  每项带 `raw`（真实集合名，给用户看/复制用）。
- `pages/tonight` 新增「云环境还没初始化」引导卡（`env.checked && !env.ready` 时显示）：
  逐条列出 5 个集合名 + 中文名 + ✓/✕、「复制集合名」、「重新检查」、
  以及 5 步操作指引（手机上用「云开发 CloudBase」小程序即可建集合）。
  同时 `loadAll` 先自检，环境不可用时**直接跳过所有查询**，不再打一堆注定失败的请求；
  未点/已点两块内容改为 `env.ready` 时才渲染，避免用户对着空页面猜。
- 用无头 Chrome 把引导卡在浅色/深色两套主题下都渲染自检过，布局成立。

**待办**：若希望「换环境/新环境一键建表」，需要 AppSecret（或云开发 API Key）
才能在 GitHub Actions 里调 `databasecollectionadd`。用户尚未提供，暂未做。

## 工具 · 云环境初始化（`tools/init-env.mjs` + `init-env.yml`）

**背景**：环境里的 5 个集合全被清掉了（见上一条），而重建非常繁琐。所以做成脚本：

- `tools/init-env.mjs`：用 AppID + AppSecret 换 access_token →
  `tcb/databasecollectionget` 查现有集合 → `tcb/databasecollectionadd` 建缺的 → 再查一遍复核。
  零依赖（Node 18+ 自带 fetch），ENV_ID 直接从 `utils/config.js` 读，不重复维护。
- `.github/workflows/init-env.yml`：手动触发，缺 `MP_APPSECRET` 时只告警不失败。
- `project.config.json` 的 `appid` 从占位符 `touristappid` 改成真实 AppID。

**重要结论（查证过官方接口清单，别再重复研究）**：

| 能力 | 能不能自动化 | 依据 |
|---|---|---|
| 新建 / 删除 / 查询集合 | ✅ 服务端 HTTP API | `POST api.weixin.qq.com/tcb/databasecollectionadd`，凭证 = 小程序 access_token（AppID+AppSecret） |
| 小程序端建集合 | ❌ | `Database.createCollection()` 官方标注「支持端：云函数」 |
| **修改集合权限 / 安全规则** | ❌ | 云开发 HTTP API 数据库章节只有 13 个接口（databaseadd / databaseaggregate / databasecollectionadd / databasecollectiondelete / databasecollectionget / databasecount / databasedelete / databasemigrateexport / databasemigrateimport / databasemigratequeryinfo / databasequery / databaseupdate / updateindex），**没有任何权限接口**；`dbmodifyacl` 只在第三方平台（`componenttcb` + component_access_token）开放 |

→ 所以「所有用户可读写」只能**在云开发控制台点**：
数据库 → 集合 → 权限 → 自定义安全规则 → `{"read": true, "write": true}`。

**顺带查清的一个知识点（很重要）**：
云开发的四种简易权限（`READONLY` 公有读私有写 / `PRIVATE` 仅创建者 / `ADMINWRITE` 仅管理端可写 / `ADMINONLY` 仅管理端）里，
**小程序端在任何一种下都不能写他人创建的数据**。而本项目需要「家人之间互相改对方的记录」
（买菜的人要能勾掉做饭的人加的采购项、任何人能撤掉别人点的菜），
所以**必须用自定义安全规则 `{"read": true, "write": true}`**，简易权限做不到 ——
这也解释了为什么当初会特意去设成「所有用户可读写」。

另一个相关坑：用自定义安全规则时，系统**不会**再自动给查询补
`_openid: '{openid}'` 条件，而且查询条件必须「覆盖」安全规则，否则报 `-502003 permission denied`。
`{"read": true, "write": true}` 恒真，所以不会踩这个坑（最省心的写法）。

**网络**：本机可直连 `api.weixin.qq.com`（0.27s 200），不需要代理。
