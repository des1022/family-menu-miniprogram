## 五、常用命令

### 小程序：上传新版本 / 生成预览二维码（推荐走云端）

在 GitHub 仓库 `family-menu-miniprogram` 的 Actions 页手动触发 `deploy-miniprogram`：
- `mode=upload` → 上传新版本（之后到微信后台"版本管理"设为体验版）
- `mode=preview` → 生成预览二维码（artifact 下载 `preview-qr.png`）

本地手动跑（需先准备密钥文件到项目根）：

```bash
export MP_APPID=wx83619ff082bae6bf
export MP_KEY_PATH=/path/to/your.key
npm i miniprogram-ci            # 首次
node scripts/upload.js preview  # 或 upload
```

### Android：出包

推送到 `family-menu-android` 的 `main` 即触发 Actions 云编译，产物取 Release 附件。
